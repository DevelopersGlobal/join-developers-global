# Contributing to Developers Global

Thank you for your interest in contributing to Developers Global! We welcome developers from around the world to join our community.

## How to Join

1. **Fork this repository** to your GitHub account
2. **Create your member profile** in the `members/` directory
3. **Submit a Pull Request** with your profile

## Creating Your Profile

1. Copy the `members/example-profile.md` file
2. Rename it to `your-github-username.md`
3. Fill in your information following the template
4. Save the file in the `members/` directory

### Profile Guidelines

- Use your actual GitHub username as the filename
- Include accurate and truthful information
- Keep your profile professional and respectful
- Add a profile picture (optional but recommended)
- Share your skills, interests, and what you're working on

## Pull Request Process

1. Ensure your profile follows the template format
2. Make sure the filename matches your GitHub username
3. Fill out the Pull Request template completely
4. Wait for a maintainer to review your submission
5. Address any requested changes promptly

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a welcoming and inclusive environment for everyone.

## Questions?

If you have any questions about the contribution process, feel free to:
- Open an issue in this repository
- Reach out to the maintainers
- Check existing issues and pull requests for similar questions

We're excited to have you join the Developers Global community! 🌍
