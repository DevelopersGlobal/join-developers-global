# join-developers-global
Join Developers Global, the global community for developers.

## How to join

1. [Fork this repository](https://github.com/DevelopersGlobal/join-developers-global/fork) to your GitHub account.
2. Copy [`members/example-profile.md`](members/example-profile.md) to `members/your-github-username.md` and fill in your details.
3. Open a pull request with your profile. A maintainer reviews it, and once it is merged you are in the members list below.

More details are in [CONTRIBUTING.md](CONTRIBUTING.md). Please also read the [Code of Conduct](CODE_OF_CONDUCT.md).
